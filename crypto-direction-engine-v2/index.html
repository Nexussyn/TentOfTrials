Le moteur combine structure multi-horizon, ordre flow, profondeur L2, dérivés, divergence cross-venue et PASR-C4. Chaque horizon possède ses poids propres. Les poids sont ajustés uniquement par des résultats futurs déjà observés. Le plan SL/TP est un plan mécanique : tant qu’il n’existe pas assez de données réelles pour apprendre un multiple optimal, le moteur utilise un prior fixe transparent. Ce prior n’est pas présenté comme une performance historique.
Sources live : Hyperliquid public Info API + WebSocket public, Binance Futures public market data. Aucun compte, aucune clé privée, aucun ordre envoyé. Les données et prédictions restent des informations de marché, pas une garantie de résultat.
